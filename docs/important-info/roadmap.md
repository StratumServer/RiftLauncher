# 📝 Roadmap

RiftLauncher doesn't keep a separate roadmap document. The living roadmap is the repository's [open issues](https://github.com/StratumServer/RiftLauncher/issues), where planned work is tracked and labeled `roadmap` as it's scoped out.

This page used to list VS Launcher's own plans from before the fork. Some of that work shipped, some didn't, and RiftLauncher's priorities now follow its own issue tracker rather than that list.
