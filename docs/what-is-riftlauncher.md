# ❓ What is RiftLauncher?

With this app you can easily install Vintage Story versions, create multiple installations with different mods, configs, worlds and so on, and make automatic backups to prevent world corruption, among other things.

It currently works on Windows and Linux. MacOS support is planned but not built yet.

RiftLauncher is a fork of [VS Launcher](https://github.com/XurxoMF/vs-launcher) by [XurxoMF](https://github.com/XurxoMF), maintained today by [Zaldaryon](https://github.com/Zaldaryon) and the [Stratum](https://github.com/StratumServer) team. The original project is archived; this fork carries its codebase forward.

{% hint style="warning" %}
RiftLauncher uses the official game files so you need an official account to play!
{% endhint %}

{% hint style="info" %}
RiftLauncher installs alongside VS Launcher instead of replacing it, and keeps its own data folder. The first time you open it, it copies VS Launcher's settings and installation icons over and leaves VS Launcher's own folder untouched, so you can keep using both. Your account usually comes across too: VS Launcher's own encrypted credential store is not copied, but if the copied settings carry a usable session it is moved into RiftLauncher's secure storage. If they don't, the launcher still shows your account by name and asks you to log in once before you can play.
{% endhint %}
